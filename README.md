# 👁️ AI Eye Detection System

🚀 A real-time computer vision project that detects eye movement, blink patterns, and vision clarity using Python.

---

## 📌 Project Overview
The **AI Eye Detection System** uses real-time webcam input to analyze eye behavior including blink detection, distance estimation, and vision clarity.

It is built using **Python, OpenCV, and MediaPipe** and demonstrates practical applications of AI.

---

## ✨ Features

### 👁️ Blink Detection
- Real-time blink tracking  
- Eye Aspect Ratio based detection  
- Automatic blink count  

---

### 📏 Distance Estimation
- Calculates user distance from camera  
- Uses eye width + focal length formula  

---

### 🔍 Vision Quality
- Blur detection  
- Classifies: Blurry / Clear  

---

## 🛠️ Tech Stack
- Python  
- OpenCV  
- MediaPipe  
- NumPy  

---

## ▶️ How to Run
```bash
pip install -r requirements.txt
